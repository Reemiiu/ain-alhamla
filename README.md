# عين الحملة — Ain Al-Hamla (الإصدار 4)

منظومة ذكية تتابع حضور أفراد حملة الحج وتحميهم من الانفصال.. حضورهم تحت نظرك في كل لحظة.

مشروع تخرّج — برمجة الحاسب وتطوير الويب، كلية التقنية الرقمية، المؤسسة العامة للتدريب التقني والمهني.

## محتوى المستودع

| المجلد | ما فيه |
|---|---|
| `database/` | ملفات القاعدة بالترتيب `01` → `13`، و`schema.dbml`، ومخططات ER (PDF و`erd/`) |
| `flutter_app/` | كود تطبيق Flutter (الحاج والمشرف) — أندرويد وويب |
| `website/` | الموقع التعريفي ولوحة التحكم (`dashboard/`) ونسخة الويب المبنية من التطبيق (`app/`) — جاهز للرفع على Netlify كما هو |
| `docs/` | العرض التقديمي v4، وبطاقة المشروع، ومصفوفة التكافؤ، ودليل الروابط |

## قاعدة البيانات بالأرقام

- **38 جدولاً**: 13 أصلية، و8 في v2، و4 في v3، و13 في v4.
- **83 علاقة**، و**21 نوع ENUM**، و**106 فهارس**، و**34 قيد CHECK**.
- **76 دالة `app_*`** تستدعيها الواجهات، و23 دالة مساعدة داخلية، ودالة عامة للأهل `family_view`.
- **Row Level Security مفعّلة على الجداول الـ38 كلها**؛ الواجهات لا تقرأ الجداول الحساسة مباشرة، بل عبر دوال `app_*` بعد التحقق من الجلسة والدور.

### ترتيب التشغيل

```
01_schema.sql                 الجداول الأصلية (13)
02_seed.sql                   بيانات تجريبية
03_connect_app_and_website.sql  الجلسات ودوال الدخول
04_migration_v2.sql           +8 جداول (المناسك، التجمعات، نبضات الموقع، التقارير...)
05_seed_v2.sql
06_offline_map.sql            الخريطة بدون إنترنت
07_migration_v3_features.sql  +4 جداول (الرفيق، نقاط اللقاء، الحرارة، الحشود)
08_migration_v4_hajj.sql      +13 جدولاً (حدود المشاعر، الأدوية، الأهل، الرسائل، المفقودات...)
09 → 13                       تحسينات لوحة التحكم والتطبيق وإصلاحات، وموقع التنبيه
```

ملاحظة: الملفات التي تضيف قيماً جديدة لنوع ENUM تبدأ بـ `BEGIN; … COMMIT;` لتجنّب الخطأ `55P04`.

## الواجهات والأدوار

| الواجهة | الدور | أين |
|---|---|---|
| الحاج | `PILGRIM` | التطبيق: الرئيسية، الخريطة، جدولي، التنبيهات، حسابي، «حجّي» |
| المشرف | `SUPERVISOR` | التطبيق + لوحة التحكم لمجموعته |
| الإدارة | `ADMIN` / `OPERATIONS_CENTER` | لوحة التحكم كاملة |
| الأهل | بدون حساب | رابط مؤقت `family.html?t=` بلا موقع دقيق |

## أبرز الوظائف

تسجيل الحضور عند نقاط التجمع، وخريطة حيّة تعمل بدون إنترنت، وتنبيه غياب وابتعاد تلقائي، وزر SOS يصل لأقرب مستجيب، وملف طبي وجهات طوارئ، وتقرير بعد كل منسك، و4 لغات. ومميزات الحج: مؤشر خطر الضياع، نظام الرفيق، نقطة اللقاء الذكية، الإجهاد الحراري، حدود المشاعر والمبيت بمنى، الأدوية والجرعات، «أنت بخير؟»، رابط الأهل، رسائل المشرف بلغة الحاج، المفقودات، عدّاد المناسك، دليل اليوم، وتقرير نهاية الحج. التفصيل الكامل في `docs/مصفوفة_التكافؤ.md`.

## التشغيل محلياً

- **الموقع ولوحة التحكم:** افتحي `website` في VS Code ← Live Server ← `dashboard/login.html` (أو `python3 -m http.server 8080` داخل `website`).
- **التطبيق:** داخل `flutter_app`: `flutter pub get` ثم `flutter run` أو `flutter build apk --release`.

حسابات التجربة: الإدارة `1010101010`، الحاج `1030303030`، وكلمة المرور `Demo@1234`.

## حدود صريحة

- حدود المشاعر تقريبية للعرض وليست الحدود الرسمية.
- ترجمات رسائل المشرف تُكتب عند الإرسال؛ الترجمة الآلية والتسجيل الصوتي يحتاجان خدمة خارجية (`audio_url` جاهز).
- الإشعارات تظهر داخل التطبيق ولوحة التحكم (تحديث كل 20 ثانية)؛ إشعار الجوال خارج التطبيق يحتاج ربط Firebase Cloud Messaging.
- المفتاح الموجود في الكود هو مفتاح `anon` العام فقط؛ الحماية تعتمد على RLS والدوال.
