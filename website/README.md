# عين الحملة — الموقع ولوحة التحكم (v2)

| المسار | ما فيه |
|---|---|
| `index.html` + `css/landing.css` | الموقع التعريفي |
| `dashboard/` | لوحة التحكم (12 صفحة) — تُفتح الواجهة حسب الدور: إدارة / مركز عمليات / مشرف |
| `app/` | نسخة الويب من تطبيق Flutter (يُبنى بأمر `نشر_عين_الحملة.command`) |
| `assets/docs/` | مخطط ERD وبطاقة المشروع، مربوطة من تذييل الموقع |

## التشغيل محلياً
افتحي مجلد `website` في VS Code ← Live Server ← `dashboard/login.html`
(أو من الطرفية: `python3 -m http.server 8080` ثم `http://localhost:8080/dashboard/login.html`).
لوحة التحكم تستخدم ES Modules، فلا تعمل بفتح الملف مباشرة (`file://`).

## صفحات لوحة التحكم

| الصفحة | الإدارة | المشرف |
|---|---|---|
| `index.html` | الرئيسية: مؤشرات الأداء وطابور الاستجابة | مجموعتي ومؤشر الجاهزية |
| `alerts.html` | الاستجابة للتنبيهات وSOS مع التصعيد التلقائي | تنبيهات مجموعته |
| `map.html` | الخريطة الحية لكل المجموعات | خريطة مجموعته |
| `gatherings.html` | التجمعات | فتح تجمع بمهلة وتسجيل الحضور |
| `reports.html` | تقارير المناسك (طباعة + CSV) | إنهاء المنسك وكتابة التعليق |
| `activity.html` / `groups.html` | سجل الشغل، والمجموعات والمشرفون | — |
| `comments.html` | كل التعليقات | تعليقاته |
| `pilgrims.html` / `trips.html` / `messages.html` | الحجاج والتنقلات والرسائل الجماعية | حجاج مجموعته وتنقلاتها ورسائلها |

`sos.html` صفحة قديمة تحوّل تلقائياً إلى `alerts.html`.

## الخريطة بدون إنترنت (2.1)
- `dashboard/sw.js` يحفظ صفحات اللوحة ومكتبات CDN وصور الخريطة التي عُرضت، فتفتح اللوحة بدون إنترنت بعد أول زيارة.
- الخريطة الحية تحفظ آخر بيانات في المتصفح. عند الانقطاع تعرضها مع شريط «بدون إنترنت — آخر بيانات محفوظة قبل …».
- في صفحة الخريطة زر **«حفظ الخريطة بدون إنترنت»**: ينزّل صور منطقة صغيرة حول مواقع الحملة فقط (≈ 430 صورة).
- نسخة التطبيق في `app/` لها `ain_sw.js` بنفس الفكرة. يُبنى من `flutter_app/web` بأمر النشر.
- الـ Service Worker لا يعمل على `file://`، فافتحي اللوحة عبر Live Server أو Netlify.

## الاتصال بالقاعدة
البيانات في `dashboard/js/supabase-config.js` (مفتاح publishable فقط، لا تضعي `service_role` أبداً).
كل كتابة وكل قراءة حساسة تمر عبر دوال `app_*` في القاعدة، وهي تتحقق من رمز الجلسة ودور المستخدم داخل الخادم.
لازم تكون `database/04_migration_v2.sql` و`05_seed_v2.sql` و`06_offline_map.sql` مشغّلة على Supabase قبل تجربة اللوحة.

حسابات التجربة وكلمة المرور في `اقرأني_v2.md` بالمجلد الرئيسي.
