تطبيق واحد بواجهتين حسب الدور، متصل بقاعدة Supabase الحية (21 جدولاً):

| الدور | التبويبات |
|---|---|
| الحاج | الرئيسية · **الخريطة** · جدولي · التنبيهات · حسابي |
| المشرف / الإدارة | مجموعتي · **الخريطة** · التجمعات · التنبيهات · حسابي |

## الجديد في 2.1: الخريطة تعمل بدون إنترنت

ضعف الشبكة في المشاعر من تحديات بطاقة المشروع، لذلك صارت الخريطة والمسافات والسهم تعمل من الجوال نفسه.

| ما يعمل بدون إنترنت | من أين يأتي |
|---|---|
| صورة الخريطة (منى والمخيم والجمرات وعرفات ومزدلفة والحرم) | محفوظة على الجهاز: تُنزَّل تلقائياً أول مرة لمنطقة صغيرة حول مواقع الحملة فقط (≈ 430 صورة، أقل من 10 م.ب)، وكل منطقة تُعرض تُحفظ أيضاً |
| موقع الحاج الحي | GPS، ولا يحتاج إنترنت |
| نقاط التجمع والنطاقات الآمنة والتجمع القادم | آخر نسخة من `app_map_data`، محفوظة على الجهاز وتتحدث كل 5 دقائق عند الاتصال |
| موقع المشرف | **آخر موقع معروف** له، ويظهر بجانبه «قبل كم دقيقة» |
| مركز المجموعة | متوسط مواقع أفراد المجموعة خلال آخر ساعة، بدون كشف موقع كل فرد للحجاج |
| المسافة والسهم وزمن المشي | تُحسب داخل الجهاز (`services/geo.dart`) بنفس معادلات دوال الخادم `_dist_m` و`_bearing` |
| رقم المشرف وبطاقة الطوارئ | آخر ملف (`app_me`) محفوظ على الجهاز، فيقدر الحاج يتصل بمشرفه حتى بدون باقة إنترنت |
| الحضور وSOS و«أنا تائه» | تُحفظ في طابور، وتُرسل تلقائياً عند عودة الشبكة بوقت الجهاز الأصلي (موجود من v2) |
| فتح التطبيق نفسه (نسخة الويب) | `web/ain_sw.js` يحفظ ملفات التطبيق بعد أول فتح |

ما يحتاج إنترنت: المواقع **الحية** للآخرين، وزر «خرائط Google».

### الملفات الجديدة
```
lib/services/geo.dart             المسافة والاتجاه وزمن المشي وأرقام صور الخريطة
lib/services/map_cache.dart       حفظ بيانات الخريطة + حساب مؤشر القرب بدون إنترنت
lib/services/offline_tiles.dart   صور الخريطة: من الجهاز أولاً، وإلا تُنزَّل وتُحفظ + حفظ المنطقة مسبقاً
lib/services/tile_store_io.dart   حفظ الصور كملفات (أندرويد / iOS)
lib/services/tile_store_web.dart  حفظ الصور في Cache Storage (نسخة الويب)
lib/screens/map_screen.dart       شاشة الخريطة للحاج والمشرف
web/ain_sw.js + web/flutter_bootstrap.js   فتح نسخة الويب بدون إنترنت
test/offline_map_test.dart        اختبارات الحساب بدون إنترنت
```

> قبل تجربة الخريطة لازم يكون `database/06_offline_map.sql` مشغّلاً على Supabase، لأنه يضيف الدالة `app_map_data`.

> صور الخريطة من OpenStreetMap (مجانية مع ذكر المصدر)، والتنزيل المسبق محصور في منطقة الحملة. للتشغيل الفعلي بآلاف الحجاج يُستبدل الرابط في `offline_tiles.dart` بمزوّد تجاري مثل MapTiler أو Stadia بنفس الصيغة.

## التشغيل

```bash
cd flutter_app
flutter pub get
flutter run -d chrome   # نسخة الويب
```
بيانات الاتصال بـ Supabase موجودة في `lib/services/supabase_config.dart` (مفتاح publishable فقط).

**للجوال (أندرويد / iOS):** المشروع حالياً فيه منصة الويب فقط. لإضافة الجوال مرة واحدة:
```bash
flutter create --platforms=android,ios .
```
ثم أضيفي صلاحية الموقع: `ACCESS_FINE_LOCATION` في `android/app/src/main/AndroidManifest.xml`، و`NSLocationWhenInUseUsageDescription` في `ios/Runner/Info.plist`.

**الفحص:** شغّلي `تحقق_التطبيق.command` من المجلد الرئيسي. يشغّل `flutter analyze` و`flutter test` ويكتب النتيجة في `flutter_app/analyze.log`.

**النشر على الموقع:** شغّلي `نشر_عين_الحملة.command`. يبني نسخة الويب داخل `website/app`.
